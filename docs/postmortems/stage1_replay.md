## 3. CPU timing baseline (Rule-5 input)

- skim-scale dummy sweep: 10,000 combos over n=3,624 rows in 0.16s -> 62,252 combos/s (0.02 ms/combo)
- backend-scale vectorized pass: 200 mask+mean over n=809,627 rows in 0.67s -> 298 passes/s

Interpretation: at skim scale the CPU already does ~62,252 selection-mask combos/s. GPU sweeps (Stage 2) are justified only for path-level replay where a single combo costs O(n_trips x path_len), not O(n_trips). That ratio is measured when the path-level replay lands; these numbers are the selection-mask anchor.
