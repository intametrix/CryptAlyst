1. What the platform is

Three runtimes in one repository. A Go platform serves the dashboard and all forecasts; a React app renders six views; a Python fleet runs model books and a GPU agent scores parameter grids. They share one contract — the envelope — and one broker.

3. The backend request path

An endpoint is a function on *Server registered in routes.go's single mux. It reads its parameters through readQuery, asks barsForRequest for data, computes with modelPath, and answers with ok or fail. Those four helpers are the whole request layer — before them, thirty-five handlers wrote their own error envelope and twenty-three parsed the symbol themselves.

The interval policy

// backend/internal/api/pipeline.go
intervalPolicies = map[string]intervalPolicy{
  "5s":  {warmup: 40,  maxBars: 1000},
  "30s": {warmup: 20,  maxBars: 1000},
  "1h":  {warmup: 120, maxBars: 1000},
  …
}

A frame's minimum and maximum live in one table. Twelve handlers previously carried their own numbers, which is how the sub-minute frames came to be untestable: the same 120-bar minimum that suits an hourly chart made a thirty-second chart impossible.

Store first, network second. barsFor answers from the local store and only calls the exchange when the store is short. That is what stopped forecasts re-downloading the same history dozens of times a minute — and it is why the data inventory panel exists.

5. The detection layers

Three independent layers decide that something is happening. They are separate on purpose: each has its own window and its own idea of "normal", so a burst that one misses another may catch.

layerquestionhow it answers
flowis the tape unusual right now?trade flow against a baseline built from the same pair's quiet periods; aggressor share, buy ratio, burst multiple
screenwhich pairs pass the thresholds?move, volume ratio, volume z-score, USD flow and 24h quote volume, all from the settings table
turtleis there a longer-horizon setup?the classic breakout rules with a risk budget: starting equity, risk per unit, position sizing
Thresholds are data, not code. /api/settings carries the numbers the screen uses, and the settings view edits them. A detection that fires too often is a settings question before it is a code question.
// a burst is measured against the pair's own baseline, not a global one
multiple = recentFlow / baselineFlow      // 26.4x = 26 times normal
zscore   = (move - meanMove) / stdMove    // unusual for THIS pair

6. Forecasting and models

Fifty models in twelve families, each a function from bars to a path. The registry is the single source of truth: name, family, whether it needs volume, and how much history it wants.

// backend/internal/api/model_registry.go
type modelSpec struct {
    name   string
    family string        // trend · damped · ema · analogue · statistical · …
    volume bool          // needs volume to compute
}

How a forecast is scored

metricmeaning, and its trap
MAPEpercentage error of the path; comparable only within the same frame and horizon
coveragehow often the actual landed inside the 90% cone; a cone that claims 90% and delivers 60% is worse than no cone
R²the trap. Computed on price levels it is dominated by the window's own spread: a model that predicts "no change" scores above 0.95. It is shown because it is conventional, not because it is decisive
skill vs flatcomputed, and the honest comparison: does the model beat simply saying "the price stays here"?
// backend/internal/forecastlab — the walk-forward grid
for each lookback in {2..50}:
    for each window in {…}:
        train on bars[0:n-window], grade on bars[n-window:n]

The optimiser runs that grid on the GPU agent when one is reachable and falls back to local scoring otherwise. The live board keeps the best-ever configuration per pair, which is what the "best" pseudo-model resolves to.

7. The envelope

The full treatment is in The Envelope, as built; what a developer needs here is the shape and the rule.

packet = { data, meta, refs }
meta   = version · plane · topic · key · producer · generation
         cid · parent_cid · computed_at · received_at · compute_ms · pipeline

Publish through envelope.Run, never by hand: it applies authority, keying, correlation and freshness before your operator computes anything, and records the refusals.

req := envelope.Request{Topic: "intel.forecast", Key: symbol, Producer: "forecast",
                        Refs: []envelope.Ref{{Topic: "market.candle", Key: symbol}}}
pkt, pipeline, err := envelope.Run(req, time.Now(), func() (any, error) { return payload, nil })
if err == nil { recordEnvelope(pkt) }

One fetch rule. There is exactly one fetch left in the app: inside ErrorBoundary.componentDidCatch. A client helper that throws there would raise a second error inside the error handler, so that call stays raw — and commented.

9. The GPU agent

The agent (cmd/cryptalas, port 8810) advertises itself, accepts sweep jobs and returns scored results. The engine keeps the best-ever configuration per symbol and falls back to scoring the platform models locally when no agent answers — which is why the board still moves with the GPU box off.

10. The fleet and its ports

Six processes make the platform. Start them in this order; each one is independently restartable.

processportwhat it does, and what breaks without it
platform8787the dashboard and every forecast endpoint. Nothing works without it
marketdata8796the Binance feed: 1s bars, top 400 pairs, aggregated to 5s and 30s. Without it the boards freeze but the page still loads
refdata8790identity: symbol, base, quote, contract type. Without it the ticker picker falls back to whatever the market feed knows
recorder8801consumes every envelope and writes the lake. Without it /api/bus answers 502 and the message-bus view goes empty
RabbitMQ61613 / 15672the envelope bus (STOMP / management). Without it packets are journalled but not broadcast
master8799the Python model books

rabbitmq-server -detached

python3 -u master.py --host 0.0.0.0 --port 8799

12. Recipes

Add an endpoint

  1. Write func (s *Server) handleX(w http.ResponseWriter, r *http.Request) in a new file under internal/api.
  2. Parse with readQuery(r); fetch with s.barsForRequest(ctx, req, extra).
  3. Answer with ok(w, map[string]any{...}) or fail(w, "reason").
  4. Register it in routes.go; test it with mocks.Market.

Add a model

  1. Write the path function: func(bars []binance.Kline, horizon, lookback int) ([]float64, bool).
  2. Register it in model_registry.go with name, family and whether it needs volume.
  3. Nothing else: it appears in /api/forecast/models, in the picker, and in the optimiser's candidate set.

Add a topic

  1. One row in topics.go: name, plane, producers, TTL, whether it is recorded.
  2. Authority now enforces who may write it; the orchestrator now schedules it.

Add a section to the forecast view

  1. Write the component with props; fetch with useResource, glossaries with useTools.
  2. Wrap it in <Section id="fl.x" title="…"> — the section supplies the error boundary, so a crash stays inside it.

14. Invariants and gotchas

invariantwhy
The packet shape never changesVariance belongs in producers and consumers. A trading field on the envelope ends the design.
Generations are per (topic, key)Not per topic. A 1m and a 4h forecast for one symbol share a counter — compare computed_at to order them, not generation alone.
Market topics are never recordedThe bus is a state channel. A price two seconds old is not history.
Recording never fails a requestThe recorder is a consumer. If the journal or the broker is down, the answer still goes out.
One clock for the appuseNow owns the interval; a timer per component was thirty timers and several stale closures.
Colour tokens are --pal-*The theme already owns --panel-2 and friends. Reusing those names silently repaints the UI.
Before you claim a UI change works: run the gate, then open the page and measure. The gate proves the component renders; it does not prove the axis labels are inside the SVG, that a chart's first point moved, or that a tooltip appears. Two of the three defects found in the last sweep were of exactly that kind.
